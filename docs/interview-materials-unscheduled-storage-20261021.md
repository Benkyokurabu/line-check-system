# 日程未定の面談資料と共有保存

確認日：2026年10月21日。

## 作成と保存の手順

1. 「面談資料を作る」で、生徒台帳から対象の生徒を直接選ぶ。面談日程は必須ではない。
2. アンケート回答や資料候補を確認し、「資料を作る」からPDF作成へ進む。
3. 個別に作成した一式PDFは、非公開ストレージと作成PCのOneDriveに保存される。共有NASへの閲覧用HTML一式の保存は別操作である。
4. 作成後に「共有フォルダに保存」を押し、保存先の選択画面で「98面談資料」を選ぶ。面談予定を選んでいない場合は「個別保存／学年 氏名（学籍番号）」に保存される。日付のある面談予定を選んだ場合は、担当先生と面談日時に基づく既存の保存先を使う。
5. 保存した生徒フォルダの「面談資料.html」から、各資料や面談記録を閲覧する。

「確定面談の資料をまとめて作成」は、日程のある予定が対象である。日程未定の生徒の資料準備には、生徒を直接選ぶ個別作成を使う。資料準備のために架空の日程を登録しない。

## 共有フォルダの書き込み許可

ユーザーの指示「そのフォルダに関しては書き込みも可能　書いておいて」により、次のフォルダとその配下は面談資料の保存・更新に必要な書き込みが許可済みである。

```text
\\TS3210\benko\03 教務部\015 各面談行事／文化会館も含む\98面談資料
```

この範囲への書き込み許可を繰り返し確認しない。既存資料を保護し、保存先が許可されたフォルダの配下であることを確認して保存する。NASのその他の場所は原則読み取り専用とする。作業ファイルと個人情報を含む照合記録は勉たん内へ保存し、Gitへ追加しない。

## 今回の確認結果

直近の個別作成はPDF作成・OneDrive保存・クラウド同期に成功していた。共有NASへの閲覧用HTML一式の保存は確認できなかったため、完成済みPDFを再利用して資料一式を保存した。新規の生徒フォルダに9ファイルを保存し、全件のサイズとSHA-256が元資料と一致することを確認した。既存資料の上書きは行っていない。

AI要約は保存時点で処理待ちだった。生徒の氏名・学籍番号、完成資料、Notion本文、作成ジョブ識別子、照合記録はこの文書とGitに含めない。

初回のブラウザで保存操作のどこが止まったかは未確認であり、日程未定が原因のコード不具合と断定しない。本番アプリのコードは変更していない。
