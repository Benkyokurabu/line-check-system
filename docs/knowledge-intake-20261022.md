# 自然文の知識取込・2026年10月22日

業務説明をローカルへ蓄積するため、自然文の受信フォルダ取込を追加した。アプリ・外部サービスへの送信は行わない。

- 実装：`knowledge/intake.mjs`、`scripts/knowledge-intake.mjs`
- 正本：`--root` で指定した勉たんフォルダの `資料集約/知識基盤/records.json`
- 入力：`資料集約/知識受信/` 直下のUTF-8テキスト・Markdown
- 原文保管：`資料集約/知識基盤/originals/`（元バイト列をSHA-256名で保管）
- 取込証跡：`資料集約/知識基盤/intake-receipts/`（版・ハッシュ・分類候補・未確認点）

## 利用

利用者はこの会話で説明するか、受信フォルダへメモを保存する。取込を動かすのはCodex側で行える。監視が停止している場合は、ファイルを置いただけでは登録されない。

```powershell
node scripts/knowledge-intake.mjs once --root "C:/Users/kudok/OneDrive/デスクトップ/勉たん"
node scripts/knowledge-intake.mjs watch --root "C:/Users/kudok/OneDrive/デスクトップ/勉たん"
node knowledge/cli.mjs search --root "C:/Users/kudok/OneDrive/デスクトップ/勉たん" --query "面談"
```

分類・訂正用サイドカーと確認済み登録の区別は `knowledge/README.md` に記載。本文は常に原文で、分類候補・未確認点は別に保持する。自動取込した文章を確認済みの事実や全体ルールとしてAIへ渡さない。

## 保護する動作

同じファイルの再巡回・別名コピーで重複登録しない。同一IDと期待版による訂正を維持し、残っている旧ファイルが最新版へ戻ることを防ぐ。保存成功後に受領票の書込が中断しても、出典の取込アクションと原文ハッシュが一致した版だけを復元する。期待版の競合や原文の改変はエラーとして残し、別の正常なファイルは処理する。

既存 `context-store` の18テストと、取込・重複・訂正・復旧・UTF-8・秘密値の非出力・ジャンクション境界・watch停止の新規テストで確認する。

## 運用上の限界

監視はローカルPCの起動プロセスであり、常時稼働サーバーではない。PC再起動後の起動設定は別の運用設定が必要。複数PCから同じOneDrive知識フォルダへ同時保存しない。 `.intake.lock` が残った場合は実行中プロセスの有無を確認し、知識フォルダを退避してから解除する。ロックを自動で消して保存を続けない。

分類候補は語句による提案で、意味理解・人の確認の代わりではない。Notion・LINEの情報取得や勉たんAIへの自動接続はこの処理には含まない。入力途中のファイルの部分保存を防ぐため、メモを保存し終えてから取込を確認する。実際の業務確認日が未指定の場合は受領票の `businessCheckedAtProvided: false` で区別する。
