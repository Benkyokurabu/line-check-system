# アンケート確認状態の自動共有（2026-09-23）

回答の確認ボタンは1件ずつ自動保存する。共有DBの保存結果を受け取ってから表示を確定し、端末内の記録は共有状態に重ねない。更新者・更新日時も表示。表示時・フォーカス/可視状態復帰・通信復帰・表示中30秒間隔で同期し、再取得ボタンも用意する。同期失敗時は前回表示と最終同期時刻を保持する。

既存の `survey_confirmations` と版照合RPCを再利用し、DDL変更はない。取得・保存とも職員認証を必須とし、現在の秋アンケート回答IDに絞る。職員の閲覧範囲は既存回答一覧と同じ全担当。回答ID一覧はプロセス内で60秒キャッシュし、同時取得をまとめる。保存APIは確定した共有状態を返す。競合時も最新状態を返し、画面で端末の操作と比較した後に利用者が再試行する。同じ内容の再送は既存RPCが重複更新を防ぐ。

旧下書き・旧確認済み記録・保存失敗した操作は「未共有の端末記録」に対象と内容を表示する。自動反映はせず、1件ずつ共有または共有状態を使用する。共有に記録がある場合も自動上書きしない。現在の回答一覧にない記録は取り込めない。旧画面からの保存はclientVersionの照合で再読込を案内する。非表示は従来通り端末内のみ。

検証: survey-confirmationsのDB試験、survey-confirmations/home-surveyのブラウザ試験、型・対象lint・本番ビルド。本番での確認は職員ログイン、認証付き取得、匿名拒否、画面表示の読み取りに限定し、実回答の確認フラグは試験で変更しない。
