面談後の一括入力

本番運用前・工藤先生の確認用。正式公開は工藤先生の試用後です。

一か所から進める流れ

①アンケートと生徒を選ぶ
既存の面談記録か新規作成かを明示
②原文を入力・音声を文字起こし
AIが職員用記録と共有文の候補を作成
③各項目を人が確認
確定した項目だけNotionへ反映
④宛先別に本文を確認
明示した宛先へ送信・結果を保存

入口

秋アンケートの「日程連絡・面談記録・LINE」から「面談後の一括入力（工藤先生の確認用）」へ進めます。

確認用画面を開く

従来の面談入力は引き続き使えます。入塾手続きの一括入力は「本番運用前」に移し、現在の機能を保持します。

入力と反映先

入力反映先
見出し・実施日・方法・当時の学年・目的・記入者Notion面談DB
職員用の面談記録面談ページ本文。元の段落と添付を保持し、変更版を追記
アンケートの対応対象回答の「対応」。面談準備は変更しない
共有内容・宛先別の本文確認済みのLINE宛先。送信前確認が必要

保存の関係

生徒 → 複数の面談案件
案件 → 対象アンケート・面談記録
案件 → 入力の版・操作履歴
案件 → 宛先別の承認・受付結果

同じ生徒・同じ日でも別の面談を作成できます。同じ原本を別案件へ二重に割り当てません。

人の判断を残す項目

  • 予定日・現在の学年・予定の方法は、実施内容として確定しません。
  • AI候補は確認待ちです。職員が入力・確定した値を自動で変更しません。
  • 判断できない項目には原文、候補、理由を残し、原本を上書きしません。
  • LINE宛先は自動選択しません。本人・続柄の確認済み宛先だけを選択できます。
  • 外部で送信済みなら根拠を入力して記録します。LINE受付と相手の閲覧を区別します。
  • 結果不明の送信は自動再送を止めます。片方だけ失敗しても成功分を重複させません。
  • 原本が他で変わった場合は反映を止め、入力を保持して再確認します。

試験では実生徒のNotion更新・LINE送信を行いません。実際の保存と送信は工藤先生が内容を確認して操作します。
