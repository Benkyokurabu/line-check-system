# LINE案内リンクを未ログインから開く修正

以前の `/interviews/trial?invitation=...` は職員セッションを前提としていた。ログイン済みブラウザだけを検証したため、LINEの新しいブラウザでは401となり、個別メニューに戻す表示になっていた。

新しい案内・確定通知には、244ビットのランダムな専用キーをURLフラグメントで付ける。ページはキーをURLから消し、同一オリジンのPOSTで確認して、Secure・HttpOnlyの専用Cookieを保存する。職員認証・権限は発行しない。キーはDBではSHA-256で照合し、通知本文は従来どおり送信監査として保持する。フラグメントは通常のHTTPリクエストやRefererには含まれない。

これはリンクの所持による限定認証であり、LINEアカウントの本人認証ではない。転送されたリンクを持つ人も当該案内を操作できるため、LINE Loginによる本人限定とは区別する。リンクは90日、Cookieは24時間有効。回答期限を過ぎた案内に新規申請はできないが、確定内容は確認できる。案内の取消・パイロット停止・工藤との確認済み紐付け解除でアクセスを失効させる。

権限は当該案内の表示、対応する検証用生徒の希望送信、当該申請の取消、日程が合わない旨の回答だけ。別案内ID、別生徒ID、別申請ID、先生の管理APIは拒否する。既存の担任、枠の版、Notion競合、明日以降、回答期限の検証は維持する。一般保護者への送信・紐付けは行わない。

適用SQLは `supabase/interview_invitation_access_20260921.sql`。既存送信済み本文は変更しない。修正案内は既存の未回答案内に専用キーを発行し、宛先の工藤を再照合して別の送信番号で1通送る。利用者が確認できるよう、こちらでは申請・承認を行わない。

検証：面談関連76件、画面14件、型・lint・build。本番ではCookieのないブラウザで専用リンクを開き、日程選択と送信直前まで確認する。キーなし・不正キー・別案内・先生APIへのアクセス拒否も確認する。
