# LINEから生徒役で面談を検証する

`/interviews/trial` は本番保護者画面と同じ日程選択UIを使う、認証必須の検証画面。個別入口の `studentPreview` から開く。既存の確認用生徒と隔離された `staff_interview_trial_state` だけを使用し、実面談・Notion・LINE通知には書き込まない。

画面はオンライン固定、最初の5日分の架空枠（13時・14時）から第3希望まで選択できる。確認から戻ると選択を保持する。申請の取り下げは既存の検証用cancel操作に変換する。工藤のLINE個別メニューの面談ボタンをこの入口に切り替える。自習室ボタンは既存の生徒役のまま。職員アカウントの権限自体は変更しない。

生徒用予約ページでは業務ナビ・Codexサポート欄を表示しない。未認証時はLINE個別メニューからの再入場を案内する。本番保護者のLINE Login設定を代替する仕組みではない。

型・対象lint・build、専用入口単体4件、関連画面12件成功。画面テストで本番予約APIへの接続がないこと、第3希望・戻る・保存・取り下げ、未認証時の表示を確認。LINEメニューの変更前定義・画像・適用結果はローカルの非公開analysis_outputsに保存する。個別キーを公開ファイルやログへ書かない。
