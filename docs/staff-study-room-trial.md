# 自習室の職員操作確認

これは検証用です。工藤・金城の管理者アカウントで、生徒役と職員役の一連の操作を確認します。予約は専用の `staff_study_room_trial_state` に保存し、実生徒の名簿・予約・LINE通知には接続しません。

- 生徒役: https://line-check-system.vercel.app/self-study-room/trial
- 職員役: https://line-check-system.vercel.app/staff/self-study-room/trial
- 個別入口（生徒役）: `/self-study-room/trial?staff=KUDO`、`/self-study-room/trial?staff=KINJO`。入力はパスワードのみです。共通入口では名前を選んでからログインします。
- 工藤・金城のパスワードは依頼により共通設定です。コードへの埋め込みはせず、管理認証を継続します。操作記録は選択されたアカウント名であり、個人の識別を保証しません。
- 事務部は個人ごとに `office` 権限で登録します。未登録の担当者は利用できません。

## 確認手順

1. 生徒役でログインし、「空席・申請状況を更新」を押します。日付・座席・時間帯を選び、「申請内容を確認」→「この内容で申請」を押します。
2. 別端末で上記の職員役URLを開き、「一覧を更新」を押します。確認用の申請を承認します。
3. 生徒役で「空席・申請状況を更新」を押し、予約確定を確認します。承認待ち・取消も双方の画面から確認します。
4. 職員画面で代理受付、却下理由、来室・退室、訂正履歴を確認します。同じ席・時間帯の申請を二人で行い、二重確定できないことも確認します。
5. 共有端末は操作後にログアウトします。

生徒役画面には管理者表示・管理画面へのリンクを表示しません。LINEの個別メニューは生徒役の入口を開きます。職員画面は勉たんトップの「自習室管理」から開きます。

確認用は10席、90分枠、1日270分まで、最終枠休止の固定条件です。本番の開室日・席数・利用資格を保証するものではありません。生徒役も職員認証を使うため、実際のLINEログイン・保護者認証・通知受信の確認は含みません。

## 運用開始の判定

操作確認OKは利用画面の受入確認です。生徒全体への運用開始には以下も必要です。

- 本番の生徒・保護者LINE認証、正しい生徒紐づけ、在籍・利用資格の確認。
- 実予約用DB・権限・開室条件の設定と、競合・取消・障害時の確認。
- 事務部担当者の個人登録、承認・代理受付・トラブル対応手順の確定。
- 正しい通知先と配信結果の確認。確認用画面からLINEは送信されません。
- 本番構成での最終通し確認と、開始対象・開始日の決定。

これらが揃うまでは実予約を有効化せず、今回の確認OKを全生徒への公開許可には扱いません。

## 実装上の分離

職員操作確認APIは毎回実セッションを検証し、管理者・事務部だけを許可します。生徒役APIは `KUDO` / `KINJO` の管理者に限定し、本人の確認用生徒番号をサーバー側で決定します。保存はバージョン条件付きで行い、競合時は409を返します。匿名・ブラウザ認証ロールには確認用テーブルの直接参照・更新権限を与えません。
