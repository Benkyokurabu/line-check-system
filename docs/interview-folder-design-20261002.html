生徒のフォルダを開けば、面談ができる

操作の流れ

生徒を選択→AI要約を開始・資料を選ぶ→PCに保存・保存先を選ぶ→面談資料.htmlを開く

AI要約は未作成・記録変更時だけ実行し、原文と結果はクラウドDBで共有する。保存はAIを待たずに進める。

生徒名フォルダの中身

確認用 生徒_2018998/
  面談資料.html     ← 面談中の入口
  staff-bundle.pdf  ← 印刷用の一式
  material-0.pdf …  ← 選択した資料ごとのPDF
  面談記録.txt
  生徒情報・注意点.txt
  資料一覧.txt
  AI要約.js         ← 後から完成した要約も反映
  保存情報.json     ← 生徒・原文の一致を確認

ネット接続を切っても、資料・直近3回の記録・生徒情報を同じHTMLで切り替えて使える。

保存後にAI要約が完成した場合

未保存

勉たんのタブが開いている間は同じフォルダへ自動追記。ローカルHTMLは追加分を読み直す。勉たんを閉じた場合は「保存済みフォルダのAI要約を更新」で同じフォルダを選び、要約だけを追加できる。

時間を短縮する箇所

  • 生徒選択時に要約を開始。完成済みで原文が同じなら再計算しない。
  • 取得直後の原文は保存時に再利用し、重複取得を減らす。
  • Notion記録は同時取得数を制限して並行取得する。
  • AI待ちを保存の必須条件から外す。

クラウドAIの認証が設定されていればサーバー上で必要時だけ実行する。未設定の場合は既存のChatGPTワーカーで実行する。
