# 業務記録の氏名と面談後画面の修正

確認日：2026年10月21日。

OneDriveの10月の原本は「004 担任業務記録簿2026年10月 対保護者.xlsx」で、指定済みの原本IDと一致した。ファイル名の空白の数に違いがあっても同じ月の原本として照合する。実際の対応日の月を使い、日付から異なる月のファイルを選ばない。

今回の不一致は、ログイン者の姓名から作った「工藤謙先生」と、Excelの氏名候補「工藤先生」の差だった。摘要・内容・結果は原本の選択肢と一致した。

- KUDOの業務記録の初期氏名を「工藤先生」にした。以前の姓名由来の初期値は、ログイン者と一致し、Excelに対応する正式候補がある場合だけ画面上で補正する。その他の氏名や、Excelに存在しない候補は推測で変更しない。
- 原本の選択肢の再読み込みボタンを常に表示する。再読み込み後も実施日・開始と終了・相手などの入力を保持する。候補が無効な場合は該当項目を表示し、業務記録欄からの反映を止めて選び直せるようにする。
- 「本人・保護者へ共有する内容」の入力欄を面談後画面から削除し、AI候補の対象からも外す。旧保存データの共有文は互換性のため保持するが、LINE本文の初期値には使わない。
- 「面談の内容をまとめる」から音声入力を削除する。文字で原文を入力し、面談記録をAIで整える機能は残す。LINEは送り先と本文を確認する既存の独立した送信操作を使う。

実際の対応内容・開始終了・結果を推測してExcelへ再記入することはしない。保存済みの入力を開いて内容を確認し、保存・反映を行う。KUDO限定の確認用という公開範囲を維持する。
