# ベンスケの運用に合わせる方針

ユーザーは、現行Notion「ベンスケ」の運用を保ち、勉たんを見やすさ・入力のしやすさを補う画面として作るよう指示した。「ベンケイ」は言い間違いで「ベンスケ」に訂正済み。

正本の統合設計によると予定はベンスケDB、記録は面談DB、生徒情報とはリレーションで接続する。現在のSQL側の予定・記録保存だけではこの依頼は完成しない。

## 今回の実装

- 職員面談画面で日付を選び「ベンスケから予定を取得」を押すと、既存カードを読み取る。新たな予約IDなどの追加を読み取りの条件にしない。
- 本番APIも既存の工藤・金城の認証済みアカウントに限定する。
- 接続先はサーバー設定 `NOTION_BENSUKE_DATA_SOURCE_ID` があれば固定。未設定ならNotion検索で「ベンスケ」「ベンスケDB」の完全一致が一つの場合だけ読む。同名複数を推測で選ばない。
- 項目定義とカードをその都度取得する。日付は「日時」、タイトルは実際のtitle型プロパティ。担当者・校舎・教室・内容・メンションは既存の型で表示する。リレーションの表示名はNotionで確認する。
- 日付検索は指定日に開始するカードが対象。前日から続く予定・日時未設定のカードは対象外と画面に明記。空き枠の自動確定・重複判定の代用にはしない。
- 通信エラー、未接続、項目不足、ページング中断は空予定に変換しない。Notion本文・DB・LINE・予約は変更しない。

## 実データの確認状況

2026-09-14、既存設定のIDはdatabases、data_sourcesの両方で404。現在の接続の検索結果9,122件を確認し、アクセス可能なデータソース9個（面談アンケート6、生徒情報、クラス変更連絡表、欠席DB）にベンスケ・面談DBは含まれなかった。保存済みの別トークンによる対象DB取得も404。

現行接続名は「塾業務システム連携」。実際のベンスケDBと面談DBへの接続権限の確認が必要。既存のNotion同期アダプターは実項目を未検証のため、自動書き込みを有効にしない。現在の実予約データと検証予約は保持する。

## 接続後に残る実装

実スキーマ・選択肢・生徒リレーション・既存カードを確認し、入力時の既定値と予定/記録の書き込みを対応づける。Notionでの直接編集の取り込み、差分確認、再送時の二重作成防止を通して検証する。一般生徒・保護者への公開とLINE通知は未許可。
