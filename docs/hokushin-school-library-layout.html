面談資料と北辰基礎資料の保存構成

生徒の面談資料と、ほかの学校を見るための北辰資料を別々のフォルダ・HTMLで使います。

生徒名のフォルダ

生徒を選ぶ → 資料を作る →「面談用フォルダを保存」

  • 📄 面談資料.html
  • 📄 指導簿・選んだ学校などのPDF
  • 📄 面談記録・生徒情報

本人の面談で使う資料だけを保存します。全学校の北辰資料は追加しません。

全生徒で1セット

北辰基礎資料フォルダ

画面上部の「北辰用フォルダを保存」

  • 📄 北辰基礎資料.html
  • 📁 pdf：全学校・学科353件
  • 📄 使い方・保存情報

必要なときに専用HTMLを開き、学校を検索します。約750MBはこのフォルダに1セットだけ保存します。

作成済みの北辰資料を開く

別々のHTMLを、必要なときに開く

どちらも保存後はネット接続なしで利用できます。北辰用フォルダだけを別のPCへ移して使うこともできます。保存し直す場合は、内容が一致する保存済みPDFを再利用します。

2026-10-03：ユーザー希望の「HTMLを分けて必要なときに開く」構成。以前の各生徒へ全学校をコピーする構成を変更しました。
