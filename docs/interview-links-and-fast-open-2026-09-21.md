# LINEリンクと予約画面の読み込み改善

職員側は生徒を選択すると担任の日程を自動取得する。「空き日程を取得」ボタンを廃止し、生徒 → 日程 → 送信の順にした。回答期限は初期値を設定し、任意で変更可能。

新規の案内LINE・確定LINEには `/interviews/trial?invitation=<UUID>` のリンクを記載。既存の工藤専用認証セッションが必要で、リンクは認証トークンでも職員ログインキーでもない。未認証では個別メニューからの認証が必要。一般保護者のLINE Loginは未開放。今回も工藤だけで検証する。

サーバーは案内IDが認証済みの生徒に紐付くことを確認し、初回表示・空き日程表示の両方で対象案内に絞る。存在しない案内・他の生徒の案内は開けない。通知文面はDBのinsert時に確定させ、同じ通知の再試行で内容を変更しない。既に送信したメッセージは書き換えない。

初回GETは `parentSummary` で本人の登録・申請・確定日時だけを読む。Notion・全校の生徒/授業・日程の更新を待たない。有効な案内があれば、画面を表示した後に `availability=1` で日程を読み込む。失敗時も申請状況を残し、再試行ボタンを表示する。

更新・取消・送信・終了・画面離脱で古い読込を中断し、世代番号でも遅い応答を無効化。空き日程が未取得の場合には希望を送信できない。希望送信と承認時のNotion確認・案内の版・予約競合の検査は変更していない。

型チェック・関連lint・本番build・面談関連76テスト・画面12テストを確認。設計HTML `interview-link-and-loading.html` は操作・390px表示を確認してブラウザで開いた。
