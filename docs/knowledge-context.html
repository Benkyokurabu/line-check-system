利用側へ返す扱い

現在の判断基準として返します。外部への更新や送信を許可するものではありません。

校舎・学年・役割などの条件が限定されている場合は、検索時もその条件を指定します。条件が不足する結果は参考情報として返します。

説明を受けた後の保存と参照

  1. 元の説明を業務記録へ保存し、手順・理由・例外・確認日を整理します。
  2. 必要な知識を分類し、引用と適用範囲を確認して保存します。訂正は同じIDの新しい版として追記します。
  3. 質問や業務の対象に合わせて検索し、判断基準と個別事例・未確認点を分けて読みます。
  4. 原資料が変わっていたら再確認し、新しい根拠で版を追加します。
場面処理
過去の説明が訂正された通常の検索は最新版のみ。旧版は履歴として保持。
元資料が変わった・読めない要再確認。現在の判断基準から除外。
個別事例・改善案・推測参考情報に分離。一般ルールにしない。
既存文書に古い説明が残る自動で全件採用せず、根拠を確認して登録。

詳細なコマンドと保存形式：共通処理の説明。業務の私的な知識データは公開Gitへ含めません。
