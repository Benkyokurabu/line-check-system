# 面談資料アプリ（各PC用）

勉たんの「面談資料を作る」画面から登録された依頼を、各PCが外向きHTTPSで取得して処理します。ブラウザから127.0.0.1への接続は不要です。以前のローカルAPIは互換用に残しています。

## 2台のPCで使う

各PCに同じ版の補助アプリと、そのPC専用の `worker.json` を設置します。このPCが主担当、もう1台が予備です。主担当が稼働中は主担当が依頼を取り、停止したときだけ予備が引き継ぎます。作成時は担当PCからNASの原本を読み、完成PDFをそのPCの `%OneDrive%\面談準備\保存済み資料` に自動保存します。PDF名には作成日時・学籍番号・重複防止IDを付け、別PCから保存しても上書きしません。`rclone` の `onedrive:` 接続が設定済みのPCではクラウドへ直接アップロードし、それ以外はOneDriveデスクトップアプリが同期します。

完成PDFは職員だけが開ける非公開保管先にも置き、画面の表示リンクは10分、保管期限は1日です。毎日の削除処理で期限切れPDFと依頼を削除します。作成PCが両方停止中のときは新規依頼を受け付けません。

「一式PDFを保存」は従来どおりブラウザのダウンロード先へ保存します。資料の原本、実行ファイル、一時PDFはOneDriveの保存済み資料フォルダへコピーしません。
アンケート回答がある生徒は、画面で選んだ回答をNotionの原本と照合し、質問と回答を改ページしながら一式PDFに含めます。複数の回答があっても選択した1件だけを使います。

中3共通資料のうち、一太郎の偏差値段階表（3ページの北辰偏差値基準資料）は面談用PDFに含めません。
高校別の北辰偏差値基礎資料は、設定済みの2026年フォルダと同階層にある年度別フォルダを自動検出します。学校ごとに見つかった最新年度をプレビューとPDF作成の両方で使うため、2027年版がある学校では2026年版を重複して入れません。コピー途中などで2027年版がまだない学校は、見つかる旧年度を表示して使います。
北辰個人成績票はNASの最新年度フォルダから各PC内の `hokushin-cache` にコピーし、日本語OCRの索引を起動時に作成・更新します。初回準備中はPDF作成を待ち、完了後は索引から最新回の本人のPDFを選びます。原本の一括コピーや索引はOneDriveへ送りません。もう一方のPCでも同じ準備が独立して走ります。

## 配布・設置

配布フォルダに `BentanInterviewMaterials.exe`、`setup.cmd`、`install.ps1`、`export-guide.ps1`、`sources.txt`、`guide-path.txt`、そのPC専用の `worker.json` と `ocr` フォルダを置き、各PCで `setup.cmd` を一度実行します。主担当と予備の `worker.json` は交換しません。`sources.txt` は `ばしょ.txt` の9行（中学部・小学部の成績通知を含む）、`guide-path.txt` は指導簿原本のUNCパス1行です。成績通知は学年に対応する保存先から、本人の最新年度・最新学期の個人成績表を選びます。校舎・学年ごとの複数ページPDFでは、学籍番号か氏名が一致する本人のページだけを取り出します。繰り返し検索するため、参照した原本は各PCの `report-cache` に保持し、NASの更新時に差し替えます。現在のユーザーのローカルフォルダに設置し、Windowsログイン時の自動起動を登録します。ExcelとNASへのアクセスが必要です。

## 更新

資料の場所を変えた場合は、配布フォルダの設定ファイルを更新して再設置します。

## ビルド

`pip install -r requirements.txt pyinstaller` の後、`python -m PyInstaller --onefile --noconsole --name BentanInterviewMaterials helper.py` を実行します。配布時は `dist/BentanInterviewMaterials.exe` を設定ファイル・`install.ps1` と同じフォルダへ置きます。
