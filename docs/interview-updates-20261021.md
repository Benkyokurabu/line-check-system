# 2026-10-21 面談記録・LINE・日程連絡の統合

10月19日に別々に保存した `21c76d7`（面談記録記入・OneDrive）と `672d517`（面談後LINE簡略化）を統合した。重なったAPI・workspace・serviceで双方の機能を保持する。

- 「本番運用前」→「面談記録記入」から、アンケートのない見学生も選び、実施月のOneDrive原本へ業務記録を記入する。案件別の行予約・二重記入防止、原本の数式・書式保持、結果表示を維持する。
- 面談後LINEは送り先・本文・送信ボタンで進む。Notion反映や確定状態、別途の本人確認登録・送信前チェックは必須にしない。入力保持・宛先の生徒照合・同文の二重送信防止・結果不明時の自動再送停止を維持する。直接LINE送信時はNotionとOneDriveへ書き込まない。
- 日程連絡は「こんにちは。工藤です。」から結びまで一つの文面を生成する。確定した日付・曜日・開始と終了を差し込み、Zoom以外はID・パスコードの案内を付けない。編集欄は全文を確認しやすい高さとした。
- ベンスケ備考へ内部のアンケートIDを追加しない。従来の識別行は対象案件の保存時に除去し、通常メモを保持する。内部の台帳・作成前候補一覧・作成開始時刻・実値照合で応答喪失後の再試行を扱い、特定不能なら再作成を止める。
