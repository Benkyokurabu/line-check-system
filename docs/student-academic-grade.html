学籍番号から現在の学年を表示

登録時の学年を固定表示せず、既存のNotionと同じ規則で算出します。

登録と紐づけ

Notionの正式学籍番号 → 生徒台帳 → 保護者LINE・登録履歴

番号変更時も面談の内部IDを保持します。在籍状態や確認済みの保護者関係は変更しません。

年度の切替

学籍番号の先頭4桁を小学校入学コホートとして使用。日本時間の3月1日に進級します。Notionのコメントには4月とありますが、実際の式は3月切替です。

正式番号がない場合は保存済み学年を使用します。保存済みの学年と過去の履歴は書き換えず、LINE登録の検索・登録一覧・面談の生徒情報を読み込む際に現在の学年を算出します。

例：2016000 → 2026年度は高2 → 2027年3月から高3。高校卒業後はNotionと同じ概算年齢表示になります。
